# BakersParadise 🧁

BakersParadise is a recipe analytics system that transforms recipe data into meaningful insights.

## Features
- Ingredient frequency analysis
- Beginner-friendly recipe detection
- Recipe complexity classification
- Preparation-time categorization
- Interactive dashboard (Streamlit)

## Technologies Used
- Python
- SQLite
- SQL
- Streamlit
- TheMealDB API

## How to Run
```bash
cd database
python3 api_data_collection.py
python3 -m streamlit run streamlit_dashboard.py
